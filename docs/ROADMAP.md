# Roadmap

## 0.1 — delivered scaffold

Owner/staff vault, event dashboard, admission scanner, ticketing overview, coupon redemption, pass issue/revoke, fan shell.

## 0.2 — device identity

One-time owner-generated pairing QR, device name, member identity, short-lived access token, refresh rotation, remote revoke, audit actor = member/device rather than generic service.

## 0.3 — concert operations

Offline queue for an explicitly enabled single gate, duplicate reconciliation, guest list search, live capacity bar, incident notes, exportable end-of-show report.

## 0.4 — fan application

Magic-link/passkey login, Signal profile, city, referrals, rewards, ticket wallet, rotating ticket QR, AREA missions, push notifications and Bandsintown follow.

## 1.0 — public stores

Separate private operator build from public fan distribution; privacy text, App Store/Play declarations, universal links, deep links, push delivery and release automation.
